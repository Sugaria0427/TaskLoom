### 2.3 系统模型、界面与验证口径

架构和部署现已按统一平台账号、个人端 L1—L3、平台 L4、固定模型池、client/executor/supervisor、各端账本及状态目录更新。所有模型请求经 L4；同一账户多个 Key 共用账户额度。重试创建新 Attempt，重复传输沿用 request_id，未知结果保留预留并核对。

第 39—42 页补全真实产品、同底座复现、成熟组合三类基线，以及 B00、B10、B01、B11、B11+FB 五组消融。当前 UI 的内存数值按“调度预留”解释，CPU/RSS 实测与完整策略收益由后续工作包接入和测量。
