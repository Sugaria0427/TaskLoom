# WP6 实验链与调度衔接修复

版本：v1.0 · 日期：2026-10-25 · 对应 PR：#6

修复围绕实验完整性、工作流保真和实际调度入口展开。运行器在发送前保存计划和意图，失败保留独立记录并继续收集已受理任务。明确拒绝保留在实验分母，未知发送保留待核对状态。

实测校准保存根任务的所有有序模型、工具阶段，使用平台派发/完成回执取得模型服务时间，独立记录平台排队。每阶段模型费用与根任务消费对账。FIFO 模拟按时间推进新就绪阶段，完整保留多轮模型调用。

本地优先级直接接入已有 ModelScheduler，沿用成本账本和连续提升上限；工具侧保留加权公平队列，同时继承 WP4 原身份预留、冲突隔离及取消行为。

回归包括拒绝/超时/5xx 提交的清单存活、完整模型—工具—模型的 21 秒重现、平台等待剔除、拒绝分母、手动优先级的活性，以及真实客户端/平台/执行器的采集—校准—仿真闭环。验证 head、命令和结果列入 PR 描述。
