# TaskLoom 个人端工作台

文档核对日期：2026-10-20；界面交付与浏览器证据日期：2026-10-15。本文依次说明界面组织、数据模型、指标口径与验收方法。运行入口及安装命令以根 README 为准。

## 1. 界面组织

个人端以会话为入口，将任务交付和调度观察放在同一个工作台中。

| 区域 | 功能 | 数据来源 |
|---|---|---|
| 左侧导航 | 新建会话、搜索、重命名、归档与恢复；切换工作台和调度监控；打开平台账号设置。 | 当前 profile 的会话记录及平台连接状态。 |
| 中央消息区 | 输入资料或添加 UTF-8 文本文件，查看助手结果、工具步骤、取消与续作，下载校验产物。 | 根任务、Attempt 和任务成果。 |
| 右侧执行面板 | 当前会话消耗、执行路径、工具名额与内存预留、模型请求名额、平台共享容量与账户额度。 | 本地调度资源池和平台反馈。 |
| 调度监控 | 任务汇总、共享平台状态、逐任务资源分配、耗时、消费与预留、本地队列趋势和执行事件。 | 同一组真实账本；趋势由当前页面采样生成。 |

桌面布局允许收起右侧面板；平板和手机使用侧边抽屉。消息框支持 Enter 发送、Shift Enter 换行；Ctrl/Cmd K 返回新会话。平台设置使用原有注册、登录和 Key 连接接口。

## 2. 会话与任务

### 2.1 身份与持久化

Conversation 是交互分组，根任务继续拥有调度份额、预算、Agent 和 Attempt。每条消息建立一个独立根任务，同一会话内允许并发提交。会话分组和消息轮数不会增加任何已有根任务的调度份额。

用户消息保存在任务的 instruction 与 documents 中，助手回答直接使用经工具校验的任务结果。页面不建立另一份助手结果账本。当前 Agent 工作流是文档统计，各条消息独立执行；跨消息上下文推理与通用编程工具仍由后续运行时扩展。

会话信息、归属和任务关联保存在当前 profile 的 SQLite 数据库。TaskState.conversation_id 为兼容字段；启动时为旧任务补建同名会话，任务与会话在一次事务内保存，重复启动保持同一关联。原始输入与产物保留。

### 2.2 操作语义

重命名只改变会话标题。归档保留任务、产物和运行中的工作，阻止继续向该会话发送任务；恢复后可继续发送。任务取消和核对续作沿用独立接口。

个人端接口沿用本地控制请求头，读取与变更均限制在当前 profile 的账号归属。会话数量上限为 256；原有根任务数量、正文大小、工具资源和预算约束继续执行。

### 2.3 文件与草稿

页面读取用户主动选择的 UTF-8 文本文件，每次最多 16 份，总量最多 512 KiB；只提交文件内容和简单文件名。文件由本地后端暂存后交给受管工具子进程。

会话历史由后端持久化。浏览器只保存界面偏好和最近的文本草稿；附件内容保留在当前页面内存中，刷新后重新选择文件。提交期间继续输入的新文本会保留到下一条消息。

## 3. 指标口径

### 3.1 本地资源

工具名额、模型请求名额和工具内存取自资源池的容量、可用量及逐 Attempt 分配。内存表示准入时的预留量。CPU 利用率与进程实际 RSS 尚未采集，页面明确区分这些口径。

输入与成果空间表示 tasks 目录下的实际文件总量，分母为个人产物预算。监控表中的资源分配取自当前实际预留，任务结束后显示资源归还状态；未确认退出的隔离预留继续展示。

### 3.2 消耗与时间

会话消耗为其根任务累计消费之和，账号消费与可用额度以平台反馈为准。模拟池显示模拟单位和模拟 Token；HTTP 后端使用平台返回的计量单位。

任务用时从任务创建到完成，包含等待与恢复。历史记录缺少完成时间时显示空值，平均任务用时只统计拥有完整时间记录的成功任务，并显示样本数量。

### 3.3 队列与事件

本地工具队列、本地模型队列、平台全局队列和账号队列分别展示。资源占用显示的是当前快照；平台信号表示最近一次反馈中的发送建议。

队列趋势记录当前页面最近 60 次有效采样，刷新后重新开始。右侧动态以会话为范围，监控页展示当前 profile 最近 80 条已加载事件。执行事件保留原始任务身份并以中文解释其状态。

## 4. 验收

### 4.1 验收方法

新增集成测试验证会话持久化、旧任务迁移的幂等性、归档的准入语义、根任务独立性与归属。新增完整进程测试通过真实平台注册、两次模型—工具工作流、资源归还及双账号隔离检查交互契约。

浏览器验收覆盖桌面、平板与手机；检查会话发送、文件输入、搜索、重命名、归档恢复、取消续作、监控切换、侧栏开合及刷新恢复。执行浏览器脚本错误检查和 axe 自动可访问性检查。

### 4.2 2026-10-15 历史结果

该次验收证据位于 agent-workspace/outputs/engineering/20261015-workbench；最终自动化结果见该目录内的验收记录。产品交付执行 tools/project.py 的 verify-isolated，确保新静态资源进入安装包并可在源码目录之外运行。

验收结果：31 项单元与集成测试、5 项完整进程测试、4 项 Linux 专项测试通过，合计 40 项。verify 和 verify-isolated 均通过，后者完成干净副本、新环境、锁定依赖安装和源码目录外双账号自检。安装包内四项界面资源与当前源文件逐字节一致。

浏览器已完成两份 Windows 换行文本的实际统计，结果为 2 个文件、14 个词；完成三任务并发、取消续作、归档刷新恢复、搜索、侧栏与设置弹窗操作。提交响应延迟测试中，继续输入的下一条草稿完整保留。1440px 桌面、820px 平板、390px 手机均无页面横向溢出；工作台和监控页的 axe 扫描未检出违规项，脚本错误检查为空。

该次交付同时修复 Windows CRLF 输入指纹误报：暂存、个人端校验、执行器校验和工具读取按同一原始 UTF-8 内容计算版本，保留换行字节。已有 4 项任务的输入及成果在界面升级后保持一致。
