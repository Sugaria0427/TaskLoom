# TaskLoom 个人端工作台与验收

文档版本：v2.0 · 日期：2026-10-28。

本文依次说明日常操作、工具与权限、对话及技能、调度观察与验收。启动方式以根 README 为准。

## 1. 日常操作

左侧创建、搜索、重命名或归档会话，中央发送消息并查看回复，右侧展示执行记录与资源。Enter 发送，Shift Enter 换行，Ctrl/Cmd K 新建会话。同一会话顺序推进；当前任务执行期间，可新建其他会话并行处理。

消息直接进入模型上下文。运行时携带最近八轮成功对话及附件路径。每条消息仍是独立根任务，拥有预算、优先级和执行 Attempt；界面会话负责交互分组。普通聊天不生成 notes.txt 或 summary.json。原有统计任务及产物保留，支持核对恢复。

点击加号上传 UTF-8 文本或 PNG/JPEG/WebP/GIF 图片，支持一次最多 16 个附件、其中最多 4 张图，合计最多 512 KiB。浏览器将图片缩小并转为 JPEG（单张最多 384 KiB、800 万原始像素）；服务端验证实际格式。GIF 按首帧处理。图片作为多模态内容交给当前模型，文本由 read_file 按需读取。

## 2. 工具与操作确认

| 工具类别 | 实际行为 |
|---|---|
| 文件读取。 | read_file 读取指定纯文本或图片，文本单次最多 64 KiB；返回截断标识。相对路径基于工作目录，Windows 盘符映射到 WSL 挂载路径。 |
| 指令执行。 | run_command 在本机 WSL/Linux 执行 shell 指令，返回退出码及最多 64 KiB 的合并输出，超时最多 120 秒。每条指令展示完整内容和工作目录，允许后执行。 |
| 附件分析。 | list_files、grep、file_stats、top_words 分别列出本轮文本附件、查找字面内容、核验词数与提取高频词。 |

平台设置中可查看中文通用提示词和当前工作目录。工作区外及 .env、.ssh、.git 等敏感路径读取需确认，读取内容会交给当前模型。确认卡提供“允许本次操作”和“拒绝”。确认等待不占用工具资源，取消使旧确认失效，等待受任务截止时间约束。

命令具有本机当前用户的文件和网络权限。用户逐条确认其内容；执行器清理服务环境变量，使用进程组与可用的 cgroup 约束资源、超时及回收后代进程。资源隔离与文件访问授权各有职责。

## 3. 对话提示词与技能

通用中文提示词指导 Agent 按用户目标回答、按需调用工具、依据工具真实回执说明操作。普通问题可以直接回复，不强制调用统计工具或返回 JSON。

输入 `/` 选择技能；点击技能标签可查看本轮注入的中文提示词，移除后恢复普通对话。技能只对本条消息生效，发送后自动清除。

| 技能 | 作用 |
|---|---|
| /notes 笔记整理。 | 阅读文本或指定文件，整理主题、关键概念和待办，保留事实与出处。 |
| /stats 资料统计。 | 调用 file_stats 核验本轮文本附件的文件数和词数，按需搜索并概括内容。词数按空白分隔计数。 |

聊天内容和执行记录保存在当前 profile 数据库；附件暂存于任务目录。浏览器保留文本草稿和界面偏好，刷新后需重新选择未发送附件。

## 4. 调度观察与验收

右侧查看本轮模型/工具 Attempt、消耗、预留、工具槽位及内存预算，展开工具记录可查看参数、结果和错误。“调度监控”展示全部根任务、分配、队列趋势及事件。内存图表示调度预留，实际进程测量在执行器回执记录。平台反馈与实际请求共用同一 L4 调用路径。

按以下顺序演示：

1. 普通对话：让 Agent 记住一个代号，下一轮询问；观察普通回答无需工具。
2. 文件与图片：上传笔记并选择 /notes，上传图片询问内容，再要求读取项目中的一个文件。
3. 指令与资源：请求一条只读指令，在确认前观察工具资源未占用；允许后检查输出与资源归还。另一轮拒绝或取消操作，检查执行记录。
4. 调度比较：不同会话并行提交工具任务，在监控页观察等待与分配，再到 /experiments 比较相同合成负载下的策略结果。仿真结果与真实执行记录分别导出。

默认仿真模型明确返回模拟回复；真实分析使用平台已配置的真实模型。自动回归入口为 tools/project.py，交付执行 verify-isolated；进程资源变更另外执行 test linux。本轮本地证据保存在 agent-workspace/outputs/development/20261028-agent-chat/。
